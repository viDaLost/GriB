# Грибник

Офлайн-определитель грибов России для Android (и iOS). Наведите камеру на гриб — приложение
покажет, на какой вид он похож, насколько он съедобен и с какими опасными грибами его путают.
Интернет не нужен: справочник и модель распознавания встроены в приложение.

> **Распознавание по фото может ошибаться.** Приложение никогда не говорит «можно есть» —
> только «похоже на» и обязательно показывает ядовитых двойников. Ешьте только те грибы,
> в которых уверены сами.

## Что умеет

- **Мобильный интерфейс.** Крупная нижняя навигация, кнопки от 68 px, пошаговый определитель, фотографии в атласе и собственные векторные иконки в лесной палитре.
- **Выбор участка фото в браузере.** Коснитесь гриба, чтобы переместить рамку; увеличьте мелкий гриб перед распознаванием.
- **Камера и галерея.** До 3 снимков одного гриба (целиком, низ шляпки, основание ножки);
  каждый снимок модель смотрит трижды (центр, приближение, зеркально), ответы усредняются.
  Вердикт: «Похоже на…», «Возможно…» (несколько вариантов с процентами) или «Не определено».
- **Уточняющие вопросы после фото.** Приложение само выбирает 2–3 вопроса, которые лучше всего
  разделяют найденные варианты (при подозрении на мухомор — первым про вольву), и пересчитывает
  результат. Ответы меняют порядок вариантов, но не могут скрыть опасный гриб, найденный по фото. Добавлен вопрос о цвете свежего млечного сока для различения рыжиков и других млечников; доступны все признаки, даже если модель не предложила нужный вопрос.
- **Безопасность прежде всего.**
  - Ядовитый вид с оценкой модели от 5% показывается всегда, даже если он не в первой тройке. Проверяется каждый снимок отдельно: усреднение не стирает предупреждение. Проценты сходства не означают вероятность съедобности.
  - Поправка на сезон меняет только порядок вариантов и никогда не прячет опасный гриб.
  - Для каждого вида выводятся опасные двойники и как их отличить.
  - Противоречивые сильные ответы разных снимков требуют уточнения. Ответы пользователя не превращают слабое фото в уверенное определение.
  - Отдельно распознаются «в кадре не гриб» и «гриб не из справочника».
- **Определитель по признакам** — работает без модели: 10 простых вопросов (что под шляпкой,
  есть ли кольцо и «мешочек» у основания, млечный сок, цвет на срезе…) → список похожих видов
  с процентом совпадения. Ядовитые совпадения показываются отдельным красным блоком.
- **Справочник 78 видов**: все основные смертельно ядовитые и ядовитые грибы России, частые
  съедобные и условно съедобные. Поиск по русским, народным и латинским названиям, фильтры по
  съедобности и типу шляпки, 43 пары «двойников» с описанием отличий.
- **Карта России офлайн**: региональные сведения для 66 видов, отдельные приближения КМВ и КЧР, выбор региона, поиск и сезон. Дополнительный слой — 479 документированных образцов из двух научных коллекций. У каждой записи есть источник; литературные сообщения никогда не изображаются точками.
- **Крупные карточки**: фотография, отдельный статус съедобности, сезон, среда произрастания и распространение.
- **Экран безопасности**: правила сбора, первая помощь, звонок 103/112.

## Структура

```
app/                    Expo / React Native (TypeScript)
  src/app/              экраны (Expo Router): главная, камера, результат, справочник, карточка, безопасность
  src/data/species/     база видов (JSON) и пары двойников
  src/ml/decision.ts    логика вердикта и предупреждений — ядро безопасности
  src/ml/classifier.ts  снимок → тензор → TFLite → вердикт
  test/                 тесты (node --test)
training/               Python: скачивание фото с iNaturalist, обучение, экспорт в TFLite
```

## Скачать APK

Готовые сборки лежат в [Releases](https://github.com/viDaLost/GriB/releases): скачайте `.apk`
на телефон и установите (разрешите установку из неизвестных источников). Каждый пуш в `app/`
собирает новый APK в GitHub Actions автоматически.

## Запуск для разработки

Нужны Node.js 20+ и одно из двух: Android Studio (Android SDK) или бесплатный аккаунт Expo для сборки в облаке.
Камера и TFLite — нативные модули, поэтому **Expo Go не подойдёт**: нужна своя сборка приложения.

```bash
cd app
npm install

# Вариант 1: телефон по USB или эмулятор, установлен Android SDK
npx expo run:android

# Вариант 2: APK собирается в облаке Expo, ссылку на скачивание пришлют по завершении
npx eas-cli@latest build -p android --profile preview
```

Проверки перед коммитом:

```bash
npm test            # 58 тестов: база видов, вердикт, определитель, уточнение, калибровка, пиксели
npm run typecheck
npm run lint
```

## Модель распознавания

Модель обучается в GitHub Actions: **Actions → Train model → Run workflow**. Workflow скачивает
фото с iNaturalist, обучает EfficientNetV2-B0 на CPU (~2–3 часа), коммитит модель и фото-эталоны
в репозиторий и сам запускает сборку нового APK. Отчёт о точности — `training/last-report.json`.
Для лучшей точности обучайте на GPU в Google Colab — см. [`training/README.md`](training/README.md).
Пока модели нет, приложение работает как справочник и определитель по признакам.

## Статус и ограничения

- Данные о видах собраны из открытых источников и **требуют проверки специалистом-микологом**
  перед публикацией приложения.
- Код камеры и TFLite проверен сборкой JS-бандла и типами, но ещё не запускался на реальном
  устройстве — первая сборка на телефоне может потребовать мелких правок.
- Лицензия проекта не выбрана.

## Изменения мобильного интерфейса

Оформление «лесной атлас»: сливочный фон, зелёные и терракотовые акценты, оригинальные SVG-иконки, адаптивная камера, кадрирование в PWA, удаление неудачных снимков и определитель с одним вопросом на экран. Обработка остаётся локальной.

Веса модели в этом обновлении не переобучались. Улучшены подготовка фото и уточнение результатов; новый показатель точности на независимой выборке не заявляется. Базовый отчёт остаётся `training/last-report.json`.

## Данные карты и воспроизведение

Карта содержит два различающихся по смыслу слоя:

1. **Примерные районы** — 3095 региональных сообщений для 66 точных принятых названий из приложения A к [Bolshakov et al., 2021](https://doi.org/10.21638/spbu03.2021.404), «Agaricoid and boletoid fungi of Russia: the modern country-scale checklist of scientific names based on literature data», Biological Communications 66(4):316–325. Сохранены страницы PDF и ссылки на региональные исследования. Это исторические литературные сведения о регионах, а не непрерывный ареал, точные места сбора или текущий прогноз. Сезон и среда берутся из атласа приложения, а не из географического свода.
2. **Коллекционные находки** — 479 образцов, 52 вида, 11 регионов; большая часть выборки из Югры. Источники: Fungarium of Yugra State University (YSU-F, DOI [10.15468/g4bk6h](https://doi.org/10.15468/g4bk6h), CC BY 4.0) и New York Botanical Garden (NY, DOI [10.15468/6e8nje](https://doi.org/10.15468/6e8nje), CC0 1.0), опубликованные через GBIF. Отбираются сохранённые образцы с определителем, номером коллекции, точным названием вида, датой и координатами, без известных географических ошибок; координатная погрешность более 5 км исключается. Неуказанная погрешность отображается явно. Определения из коллекций и публикаций нами не перепроверялись.

**КЧР:** в своде есть сообщения для 44 видов нашего атласа, в том числе для соснового и елового рыжиков. **КМВ:** отдельное приближение района; список использует только сообщения по Ставропольскому краю целиком (3 вида в выбранном источнике). Это не подтверждение находок внутри КМВ. Для рыжиков в КМВ в этой выборке данных нет. Пробелы покрытия не означают отсутствия гриба. Охраняемые виды из базы исключены; сведения о регионе не дают разрешения на сбор.

Контуры России и административные границы: [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/), public domain, схематичное отображение. Все JSON встроены в приложение, запросы к GBIF при открытии карты не выполняются.

Воспроизвести коллекционный снимок (Python 3, доступ к GBIF):

```bash
cd app
python scripts/import-map-records.py
```

Воспроизвести региональный снимок (Python 3 и `pdftotext`): скачайте [приложение к статье](https://biocomm.spbu.ru/article/download/7362/8648) и [Natural Earth admin-1 GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson), затем:

```bash
cd app
python scripts/import-map-ranges.py checklist-supplement.pdf admin1.geojson
```

Импорт литературы сопоставляет только точные заголовки принятых видов, без автоматического распространения синонимов на современный вид. Коллекционный импорт ограничен двумя рассмотренными наборами и первой страницей до 300 результатов на вид: это воспроизводимая частичная выборка, а не полный каталог всех находок России.
