# Обучение модели распознавания

Модель — EfficientNetV2-B0, дообученная на фото с [iNaturalist](https://www.inaturalist.org).
Используются только наблюдения исследовательского уровня (вид подтверждён сообществом)
и только фото со свободными лицензиями: CC0, CC BY и CC BY-NC.

Кроме видов из справочника, модель учит два служебных класса:

- `__not_mushroom__` — в кадре не гриб (растения, насекомые, моллюски);
- `__other_fungus__` — гриб, которого нет в справочнике. Без него модель тянула бы
  любой незнакомый гриб к ближайшему известному виду.

## Самый простой способ — Google Colab

1. Откройте [`gribnik_colab.ipynb`](gribnik_colab.ipynb) в Colab: «Файл → Загрузить блокнот» или по ссылке с GitHub.
2. Включите GPU: «Среда выполнения → Сменить среду → T4 GPU».
3. Выполните ячейки по порядку. Скачивание займёт 30–60 минут, обучение на T4 — 1–2 часа.
4. В конце скачается архив `gribnik-model.zip`. Распакуйте его в корень репозитория и закоммитьте.

## Вручную (машина с видеокартой)

```bash
cd training
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python download_inat.py --per-species 400   # фото → data/raw, список → data/manifest.csv
python train.py                             # → models/gribnik.keras, models/report.json
python export_tflite.py                     # → app/assets/model + app/src/ml/modelAsset.ts
```

`download_inat.py` можно прерывать и запускать снова: списки фото кешируются в
`data/cache`, уже скачанные файлы пропускаются.

## Что смотреть в отчёте

`train.py` печатает и сохраняет в `models/report.json`:

- `top1` / `top3` — точность на отложенной выборке (10% наблюдений, не участвовавших в обучении);
- `dangerousConfidentMisses` — **главная метрика безопасности**: случаи, когда ядовитый
  гриб уверенно (≥70%) принят за съедобный. Цель — ноль. Если их много, добавьте фото
  этих видов (`--per-species 800`) и переобучите;
- `temperature`, `eceBefore` → `eceAfter` — калибровка: насколько «90% уверенности» модели
  соответствует 90% верных ответов (ECE, чем меньше, тем честнее). Температура подбирается на
  валидации и записывается в модель; приложение применяет её само;
- `perClass` — точность по каждому виду, от худших к лучшим.

Ядовитые виды при обучении весят больше (`--danger-weight 2.0`): лишняя тревога лучше пропуска.

## Обучение в GitHub Actions

Workflow «Train model» обучает модель на CPU без видеокарты. Задача GitHub Actions живёт не
больше 6 часов, поэтому обучение идёт до 4 этапов подряд: каждый учит, пока успевает,
сохраняет состояние (`models/state.json`, `models/checkpoint.keras`) в артефакт, а следующий
этап продолжает с той же эпохи (`train.py --resume`). В конце — калибровка, отчёт, экспорт
модели и фото, коммит и пересборка APK и веб-версии.

По умолчанию: до 600 фото на вид, 4 эпохи «головы», 16 эпох дообучения всей сети.

## Проверка кода без интернета

```bash
python make_synthetic.py && python train.py --smoke && python export_tflite.py --out-dir /tmp/smoke
```

Модель на синтетике бесполезна — это только проверка, что скрипты работают.
Флаг `--out-dir` не даёт подключить такую модель к приложению.

## Контракт модели и приложения

| | |
|---|---|
| Вход | `float32 [1, 224, 224, 3]`, RGB, значения 0..255 (нормализация встроена в модель) |
| Предобработка в приложении | центральный квадрат снимка → 224×224 (`app/src/ml/classifier.ts`) |
| Выход | `float32 [1, N]`, softmax |
| Метки | `app/assets/model/model-meta.json` → `labels` — id видов из `app/src/data/species/*.json` |

Тест `app/test/species-data.test.ts` проверяет, что все метки модели есть в базе.

## Лицензии фото

Авторство каждого фото сохраняется в `data/manifest.csv` (поля `license` и `attribution`).
Фото с лицензией CC BY-NC запрещают коммерческое использование. Если приложение будет
платным, скачивайте только `--licenses cc0,cc-by`.
